# 👑 Return of the King

A retro-inspired 2D platformer built with **Godot Engine** and **GDScript**.

"Return of the King" is my first game development project and one of the projects that made me fall in love with building things. Featuring collectibles, score tracking, sound effects, and animated gameplay, it marked my first complete experience in creating a playable game.

---

## 🎮 Features

* 🪙 Coin collection system
* 📈 Score tracking
* 🎵 Background music and sound effects
* ✨ Animated characters and collectibles
* 🗺️ Progressive level design
* 🔄 Player respawn system
* 🎮 Classic 2D platformer gameplay

---

## 🛠 Built With

* Godot Engine
* GDScript

## 🌟 Inspiration

This project was created after participating in the **"Game Forge: Build Your First Game"** workshop organized by the **DITU ACM Student Chapter** in collaboration with **Godot Engine**.

Inspired by what I learned, I spent the following six days building **Return of the King**, which became my first complete game project.
